# TKT-foundation-091: Comma-coded identity matching — `cmpOrFundCode` token resolution for the 8 unresolved XU030 companies, honest disambiguation when multiple candidates share the symbol, and the WAF-blocked code-default User-Agent fixed at the source

- Status: in-review
- Size: S
- **Priority: P1 — follow-up slice 3a of the 2026-10-27 live-run wave: 8 of 30 XU030 companies (BIMAS, ENKAI, GARAN, ISCTR, KRDMD, SISE, VAKBN, YKBNK) have no statements, no DCF baseline inputs and no financials purely because identity resolution fails on them.**
- **The verified live root cause (run 301, recorded on 087):** KAP's `POST /tr/api/search/combined` returns these companies with a **comma-joined `cmpOrFundCode`** (e.g. GARAN → `"garan,tgb"`, with multiple candidate rows), and `KapPublicCompanyIdentityResolver.Classify`'s **exact-equality** rule (`hit.CmpOrFundCode == symbol`) can never match — the same comma-coding convention TKT-foundation-046 fixed for VYK's `VykCompanyDirectory`. The resolution is `COMPANY_IDENTITY_UNRESOLVED`, named+counted (honest), but the companies stay unfetched forever.
- **What to implement:**
  1. **Comma-split token matching in `Classify`:** a company hit (`searchType` `C`) is a candidate when the bound symbol is one of the **comma-split tokens** of `cmpOrFundCode` (OrdinalIgnoreCase, trimmed — the 046 rule class applied to this source's field). The exact-equality path is the degenerate case of the token rule (single-token codes unchanged, ASELS green).
  2. **Honest disambiguation (the 046 divergence, deliberate and pinned):** where **multiple distinct company candidates** share the symbol token, the symbol is `COMPANY_IDENTITY_AMBIGUOUS` — named, counted, nothing stored, **never pick-one and never silent last-wins** (046's VYK last-wins + conflict warning is a directory-of-record posture; this source's answer is a search result list, so an unresolved ambiguity stays unresolved until a disambiguation rule is evidenced — if the live captures show a deterministic tie-break the source itself supports, e.g. exactly one candidate whose token list *starts with* the symbol, that finding is recorded and routed to the user before it is implemented, never smuggled in).
  3. **The committed capture (orchestrator-owned or the ticket's first step; one paced request per unresolved symbol at most — ≥3 s, single-flight, honest UA):** the search answers for the unresolved symbols (at minimum GARAN and a second, e.g. BIMAS or YKBNK) committed to `RealSourceCatalog.cs` as doubles — the map/resolution rules are only ever authored against committed bodies. The remaining unresolved symbols' answers may be derived in memory from the committed shapes (the 080 mutation doctrine) — no CI test ever calls kap.org.tr.
  4. **The UA code-default fix (the 087 live finding, one line + its test):** `KapPublicSourceOptions.DefaultUserAgent` still carries the WAF-blocked parenthetical (`…DegerliBot/0.1 (kap.org.tr public-site reader; polite, paced, single-flight)` — HTTP 666 on every route, probe-verified); the code default becomes the **live-verified passing string** `Mozilla/5.0 (X11; Linux x86_64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/124.0 Safari/537.36 Degerli/0.1` (honest self-identification, no comment), the dev-stack config override becomes redundant (removed by the orchestrator as a recorded ops step, not by this ticket), and a test pins the default so the blocked string cannot silently return. The politeness posture (≥3 s, single-flight) is untouched.
- **Pinned non-goals:** no walk/decode change (the statements lane picks the companies up automatically once mapped — never-walked-first ordering already puts them at the front of the next pass); no VYK identity change; no scheduled identity cadence (087's admin-trigger posture stands).
- Traces to: FR-MDF-002 (company-scoped fetch — the identity precondition), FR-MDF-008 (provenance), FR-MDF-012 (named+counted skips, never a guessed mapping), TKT-foundation-046 heritage (the comma-coding fix class), TKT-foundation-087 heritage (the live finding this closes).

Non-regression: `KapPublicIdentityTests` (the ASELS exact-match cases green, unchanged), `KapPublicIdentityJobTests`, `KapPublicSourceTests` (the UA/honest-posture cases — the default-string pin is an additive delta), `KapPublicStatementsIngestTests` re-run green. **Live criteria (orchestrator-owned, recorded verbatim):** (i) one paced `kap-public-identity` run over the shipped XU030 — resolved/inserted/unresolved counts verbatim, the 8 symbols resolved or named under their honest reason (ambiguity is a legitimate outcome, recorded, not forced); (ii) a following `Source = kap-public` statements pass walks the newly-mapped companies (never-walked-first) and writes their statements — per-company counts verbatim.
