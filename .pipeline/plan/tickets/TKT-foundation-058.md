- **PLANNER-PINNED DESIGN:**
  1. **Ingest lane:** a `shares` job (new `src/Ingestion/Shares/` lane) fetches `/memberSecurities` through the existing Kap source client (one paced call per run — the 046 members-fetch precedent: one directory snapshot per run, cached), decodes the security lines, and writes a **per-instrument share-count store** (new `share_counts` table: `instrument_id`, `shares_outstanding`, `recorded_at`, `source_ref` — one row per instrument, input-aware in-place overwrite per the 042/050 precedent on re-run).
  2. **Matching:** security lines match our instruments by `borsaKodu` (primary) / `isin` (fallback), keyed on the **trading-open line** (`borsadaIslemeAcik`). **Multi-tertip aggregation is an evidenced hypothesis, not an assumption:** ASELS's A+B lines sum to the real 4.56B count — the implementation aggregates `currentCapital` across the instrument's security lines and the live cross-validation (item 4) confirms or refutes per company; a refuted aggregation rule is recorded, never shipped.
  3. **Unit question — pinned live criterion, never assumed:** `currentCapital` may be paid-in TL or a share count (fractional values suggest TL; count = capital/nominal if so). **MUST be cross-validated against the known real counts** (ASELS 4.56B, THYAO 1.38B, TUPRS 1.93B, GARAN 4.2B, AEFES 592M) before any value is served. If the unit is TL and no nominal is available from the capture, that is an honest finding: the count stays unserved (no fabricated division, no zero) and the ticket records the gap.
  4. **Honesty on unmatched instruments:** instruments with no memberSecurities line (the 5 archive-absent members — GLRMK, PAHOL, TRALT, TRENJ, TRMET) stay **honestly absent** in the store and serve as dashes/nulls downstream — never zeros (the 031/052 doctrine).
  5. **Serving seam (in scope):** the stock payload exposes `sharesOutstanding` + `asOf` (stock-fundamentals endpoint), honest-null where absent. **Downstream consumers stay their own tickets** — pinned seams only: per-share metrics (`MetricsEngine`), multiples/market-P/E (`MarketSnapshotEngine`, BR-MOV-010's exclusion doctrine), DCF baselines.
  6. **Cadence:** minimal — the job is admin-triggerable now; share capital changes rarely. Scheduled cadence (e.g. morning-chain membership) is a later decision, its own slice — recorded, not scoped.
