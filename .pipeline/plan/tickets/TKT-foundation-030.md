- Root cause (classified by the planner on 2026-10-19, evidence below): **(a) date-dependent test/fixture defect — the known "Sunday calendar-vs-anchor" flake** (`run-report.md` standing follow-up). It is NOT a product regression and NOT primarily a test-plan wording defect. The failing assertion `tests/e2e/src/market-macro.spec.ts:102` (`USD_TRY` stale-badge `toHaveCount(0)` → "Expected 0, Received 1", TC-MOV-024) is honest: on a **Sunday CI start** the now-anchored seed inserts the daily macro rows (`USD_TRY`/`EUR_TRY`) with `recorded_at = anchor.T 21:30 UTC` where `T` is backed to the **preceding Friday**, so `MacroFreshnessService` (`.pipeline/testing/market-overview.md` · `src/Ingestion/Macro/MacroFreshnessService.cs`) computes `ageDays = today − recorded_at = 2 > 1` against the daily tolerance and the product **correctly** marks a never-missed daily series stale. The seed intended "fresh" (FU §7 `recorded_at = T 21:30`; static `FixtureMacroFreshness` even reports `IsStale = False` because it measures against anchor `T` = Friday — the anchor's "today", not the wall clock). **Evidence: (1) deterministic reproduction on the real assembly** — `FixtureAnchor.NowAnchored` + `FixtureUniverse.Build` at seed day 2026-10-16/17/18/19 yield `USD_TRY.recorded_at = 2026-10-16 21:30` for the Fri/Sat/Sun seeds (T backed to Fri) and `2026-10-19 21:30` for the Mon seed; `today − recorded_at` = 0 (Fri), 1 (Sat), **2 → stale (Sun)**, 0 (Mon). **(2) CI correlation, 1:1 with the seed weekday** — E2E green on every Sat 2026-10-17 run (last green `39079438571`, 23:32Z) and on every Mon 2026-10-19 run (`39243450581`, the current dev HEAD, green), but red on **every** Sun 2026-10-18 run starting `39085551576` (01:11Z) through `39148110049`, all the same `TC-MOV-024` assertion; the mid-week 2026-10-14 reds were a different defect (`TC-RES-034`, date-format, fixed by `TKT-res-011`). No earlier Sunday counterexample exists: the spec only joined the CI suite on 2026-10-14 (TKT-mov-006, commit `dde3949`); the 2026-10-11 Sunday runs ran a 12-test suite without `market-macro.spec.ts`. **Excluded — (b) product regression from 027's EVDS migration:** the compose.ci fixture stack seeds `macro_values` directly and runs no live EVDS source; the first red (`39085551576`, 2026-10-18T01:11Z) predates PR #102's merge (`c36a3fe`, 2026-10-19), and the post-#102 run is green. **Excluded as primary — (c):** the fixture contract prose is the stale line only in the sense that FU §7/§8.3 documents `recorded_at = T 21:30` without reconciling the trading-day-backed anchor against the age-based runtime freshness — a doc alignment bundled below, not the defect itself.
