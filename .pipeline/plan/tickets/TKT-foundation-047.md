- **PLANNER-PINNED DECISIONS (verify from code was done; the coder implements, never re-decides):**
  1. **Source availability — honest, probe-gated.** Source-verified facts: the production prices source is İş Yatırım `HisseTekil` (`appsettings.json` `Ingestion:Prices:Path`, `…/Data.aspx/HisseTekil?hisse={symbol}&startdate={date}&enddate={date}`); the envelope is **daily-bar shaped** (`IsYatirimPriceDecoder`: `HGDG_TARIH` dd-MM-yyyy, `HGDG_KAPANIS`/`HG_KAPANIS` close, `HGDG_MAX/MIN`, `HGDG_HACIM` volume; `HGDG_AOF` open present but deliberately not decoded) — **no intraday/last-price field, no sub-day timestamp**. All repo captures are historical windows (2026-10-06..08). **Whether the endpoint serves a current-day row during the session is NOT verifiable from code or captures** — and 043's evidence (progressive EOD publication at ~20:30, 23 symbols appearing on the 23:36 re-run) argues it may not. Therefore: the lane is built **behind the existing envelope detection** (the adapter already parses İş HGDG *and* Yahoo chart envelopes — `IsYahooEnvelope`; the documented contingency in `PricesSourceAdapter`'s header is "repoint `BaseUrl` at Yahoo Finance (`.IS` tickers)"). **First live gate = one paced single-symbol probe mid-session** (orchestrator-run, see live criteria): if İş serves a same-day row, the sweep uses İş; if not, the intraday fetch repoints at the delayed-quote Yahoo contingency (honest `asOf`, never fabricated freshness). The choice is config (`Ingestion:Intraday:BaseUrl`/`Path` mirroring the Prices pattern), never a code fork; the probe outcome is recorded verbatim on this ticket.
  2. **Cadence — every 2 hours during the session, four sweeps:** cron `"15 11,13,15,17 * * 1-5"` (Istanbul; 11:15/13:15/15:15/15:15+2h=17:15 — last sweep 45 min before the 18:00 close). Chosen mid-hour+15 to avoid the existing schedule set (macro-daily 08:00, morning chain 08:30, macro-cpi 09:30, fund jobs 19:00–19:10, EOD chain 20:30). Rate budget: prices `RequestDelayMs: 500` → a 100-constituent sweep ≈ 1–2 min paced; 4 sweeps/day ≈ 400 calls — comfortably inside the source's tolerance and the user's "hour or 2 hour" wording. The interval is **one config constant** (user-adjustable to 1 h later without a ticket).
  3. **Storage — a new `intraday_quotes` table, never `daily_prices`.** Columns: `instrument_id`, `session_date`, `fetched_at` (timestamptz, UTC), `last_price`, `day_volume` (nullable), `source_ref`. One row per instrument per session, **updated in place per sweep** (the 042 input-aware-overwrite precedent: identical → `unchanged`, changed → overwrite + `rewritten` stat; historical sessions immutable). EOD closes stay pure in `daily_prices`; an intraday value is never a close.
  4. **State contract (frozen here; 049 builds Web against it):** overview + stock-page price payloads gain `priceState: { state: "intraday" | "close", lastPrice, prevClose, changePct, asOf, sessionDate }`. Semantics: `changePct` is **vs the previous session's close** (from `daily_prices`; Mondays vs Friday). During session after ≥1 sweep → `intraday` with the sweep's `asOf` ("not final"). **From the 18:00 close until the EOD chain lands (~20:30): still `intraday` with its last `asOf`** — honest "last update HH:MM — not final"; the UI never freezes or relabels it as close (planner-pinned over a 18:00 freeze: the close-in-formation must not masquerade as final). Once the session's EOD close is stored → `close` sourced from `daily_prices`. Weekends/holidays → `close` of the last completed session (freshness per 037's stored-trading-day rule; 048 extends it to holidays).
  5. **Honest per-symbol accounting:** the sweep applies 043's no-data doctrine from the start (a symbol with no same-day row is counted, never invisible) — implemented in the new lane's files only; **`PricesJob.cs` is NOT in scope** (043 owns it; the adapter is reused read-only).
